## 2. Recommended flat-color target — Icons8 Flat Color Icons

If you move to a flat multi-color style, the cleanest legally-free option is the open-source **"Flat Color Icons"** set (originally published by Icons8).

| Field | Value |
|---|---|
| Pack | Flat Color Icons |
| Source repository | `github.com/icons8/flat-color-icons` |
| Format | SVG (transparent background) |
| Licence | **MIT License** |
| Attribution required? | **No** (MIT) |
| Commercial use | **Permitted** |

> Important distinction: icons downloaded from the **icons8.com website UI**, **flaticon.com**, **freepik.com** or **vecteezy.com** free tiers generally **require attribution** (a visible credit link) or a paid licence. The **`icons8/flat-color-icons` GitHub repository specifically** is MIT and needs no attribution. Prefer the GitHub repo to avoid attribution obligations on a commercial site.
